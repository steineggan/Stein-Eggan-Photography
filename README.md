# Stein Eggan Photography Journal

Profesjonell statisk HTML/CSS/JS-side basert på Costera-designets farger, typografi og premium-uttrykk, men omarbeidet til en fotojournal.

## Filer
- index.html
- styles.css
- script.js
- README.md
- vercel.json

## Publisering på Vercel
Denne siden er statisk og trenger ingen build-prosess. Last opp filene til GitHub og importer repoet i Vercel.

Vercel-innstillinger:
- Framework: Other
- Build Command: tom
- Output Directory: tom eller .

## Redigering
- Bytt bilder ved å endre `src="..."` eller `background-image:url(...)` i index.html.
- Bytt tekst direkte i index.html.
- Behold fargevariablene i styles.css dersom du vil beholde Costera-paletten.
